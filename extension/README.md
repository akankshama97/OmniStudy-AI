# OmniStudy AI - Chrome Extension

### How to Install in Google Chrome / Brave / Edge:
1. Open Chrome and go to `chrome://extensions/`
2. Turn ON **"Developer mode"** in the top right corner.
3. Click **"Load unpacked"** in the top left.
4. Select this `extension` folder (`OmniStudy_AI/extension`).
5. Open any YouTube lecture (e.g. https://www.youtube.com/watch?v=kKKM8Y-u7ds).
6. You will see a glowing **"⚡ OmniStudy Notes"** button right under the video!
7. Click it to open OmniStudy AI with prefilled notes in 1 click.
